# Київські ярмарки — збір переліку локацій

Невеликий проєкт для отримання **лише текстового переліку сезонних ярмарків** із новин Порталу Києва. Використовує Playwright + Chromium — за підходом `OSBB-D2A/dtek-kem-json`.

## Що створюється

Після успішного запуску в `output/` з'являться:

- `fairs.json` — структурований список дат, днів тижня, районів і адрес.
- `fairs.txt` — той самий перелік у текстовому форматі.

До результату не додаються HTML-сторінки, зображення, меню або рекламні блоки. Комунальні ринки, якщо вони згадані окремо в статті, не включаються до списку ярмарків.

## Ручний запуск у GitHub

1. Відкрийте **Actions**.
2. Оберіть **Київ — збір сезонних ярмарків**.
3. Натисніть **Run workflow** → **Run workflow**.
4. Відкрийте завершений запуск і завантажте артефакт `kyiv-fairs-data`.

Розклад автоматичного запуску навмисно не налаштований: workflow запускається вручну.

## Локальний запуск

Потрібен Python 3.11 або новіший.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
playwright install chromium
python src/scrape_fairs.py
```

За замовчуванням скрипт відкриває:

`https://kyivcity.gov.ua/news/tsogo_tizhnya_u_stolitsi_proydut_sezonni_yarmarki_perelik_lokatsiy_1053155/`

Іншу адресу можна передати через змінну `FAIRS_URL`.

## Формат JSON

```json
{
  "source_url": "https://kyivcity.gov.ua/...",
  "title": "Заголовок новини",
  "published_at": null,
  "scraped_at": "2026-10-18T...",
  "fairs": [
    {
      "date": "2026-10-20",
      "date_text": "20 жовтня (вівторок)",
      "district": "Голосіївському",
      "address": "просп. Науки, 88"
    }
  ]
}
```

Дата в ISO-форматі визначається за датою в тексті статті та її датою публікації. Якщо надійно визначити рік неможливо, `date` буде `null`, а початковий текст дати залишиться в `date_text`.

## Надійність і обмеження

- Скрипт перевіряє, що сторінка відкрилась і знайдено хоча б один запис ярмарку.
- Якщо сайт повернув сторінку перевірки доступу, помилку або змінений макет, скрипт завершується з помилкою і не оголошує порожній результат успішним.
- Playwright не гарантує проходження CAPTCHA або захисних перевірок. Проєкт не намагається обходити їх.
- Якщо редакція змінить розмітку новин, може знадобитися оновити CSS/DOM-логіку вилучення тексту.

## Джерело

Портал Києва — сторінка новини, вказана у `FAIRS_URL`.


## Waze feed для ярмарків

Workflow **Build Waze fair feed** формує `outpoot/feed_fair.json` у форматі CIFS із датами майбутніх ярмарків з офіційного GIS API Києва. Геометрія та назви вулиць беруться з `data/waze-location-mapping.json`; включаються лише записи, де `description = "Ярмарок"`. Для кожної дати час встановлюється на **07:00–17:00** за часовим поясом `Europe/Kyiv`.

Workflow запускається вручну, щодня за розкладом і після змін генератора або mapping-файлу. Записи API, які неможливо однозначно зіставити з геометрією, пропускаються та виводяться в лог, щоб не створювати неправильні перекриття.
